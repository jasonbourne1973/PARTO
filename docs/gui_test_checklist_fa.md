# چک‌لیست تست GUI واقعی — برای داور/مدیر پروژه

این چک‌لیست همان مسیرهایی است که در `verify_fixes16.py` به‌صورت headless (offscreen)
با پیش/پس‌شرط دیتابیس/فایل تأیید شده‌اند ولی **کلیک واقعی، دیالوگ‌های modal،
file picker و بازکردن فایل با برنامهٔ خارجی** فقط با اجرای واقعی قابل اثبات‌اند
(`NOT_TESTED - GUI EXECUTION REQUIRED`). هر ردیف یک پس‌شرط قابل مشاهده دارد؛
«کلیک شد و خطا نداد» کافی نیست.

## پیش از شروع
```bash
python -m venv venv && source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
python verify_fixes16.py                              # باید «۹۳ موفق / ۰ ناموفق» بدهد
python main.py                                        # ورود: admin / Admin@123 (تغییر رمز اجباری)
```
(`verify_fixes16.py` روی دیتابیس موقت کار می‌کند و به `database/partow.db` دست نمی‌زند.)
