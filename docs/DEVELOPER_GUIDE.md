# راهنمای توسعه‌دهنده PARTOW

## ساختار پروژه

PARTOW/
├── config/           # تنظیمات و ثابت‌ها
├── dal/              # لایه دسترسی به داده
├── data/             # داده‌های اولیه (شایستگی‌ها)
├── database/         # اتصال و مدیریت دیتابیس
├── docs/             # مستندات
├── logs/             # فایل‌های لاگ
├── models/           # مدل‌های داده
├── reports/          # گزارش‌های تولیدشده
├── services/         # لایه سرویس (منطق کسب‌وکار)
├── tests/            # تست‌ها
├── utils/            # ابزارهای کمکی
└── views/            # رابط کاربری
    ├── dialogs/      # دیالوگ‌ها
    └── pages/        # صفحات اصلی

## اصول توسعه

### 1. جداسازی مسئولیت‌ها

- View: فقط نمایش و دریافت ورودی
- Service: منطق کسب‌وکار
- DAL: دسترسی به داده
- Model: ساختار داده و اعتبارسنجی

### 2. ایجاد یک سرویس جدید

از کلاس BaseService ارث‌بری کنید و متدهای مورد نیاز را پیاده‌سازی کنید.

### 3. ایجاد یک DAL جدید

از DatabaseConnection برای اتصال به دیتابیس استفاده کنید.

### 4. ایجاد یک مدل جدید

از BaseModel ارث‌بری کنید و متد validate را پیاده‌سازی کنید.

### 5. لاگ‌نویسی

از توابع موجود در utils/logger.py استفاده کنید.

### 6. مدیریت خطا

از کلاس‌های خطا در utils/error_handler.py استفاده کنید.

### 7. نوشتن تست

تست‌ها را در پوشه tests/ قرار دهید و از unittest استفاده کنید.

## استانداردهای کدنویسی

### نام‌گذاری

- کلاس‌ها: PascalCase (StudentService)
- توابع و متدها: snake_case (get_student_by_id)
- متغیرها: snake_case (student_name)
- ثابت‌ها: UPPER_SNAKE_CASE (MAX_RETRY_COUNT)

### Docstring

برای هر تابع، توضیح کامل بنویسید.

## انتشار نسخه جدید

1. به‌روزرسانی version در config/settings.py
2. اجرای تست‌ها: python -m unittest discover tests
3. ایجاد Migration (در صورت تغییر دیتابیس)
4. ایجاد Backup از دیتابیس
5. تست کامل سناریوها
